Guide

  • Algorithm preset: uses built-in settings aligned with the matching repository YAML; the file is not read at runtime.
  • Environment: configure the common environment, CARLA, route, and observation fields.
  • Reward: the registered handler is selected by the algorithm preset.
  • Import round trip: imported YAML becomes the export base, so fields not exposed in this editor are preserved.
  • Export: generates the algorithm/policy/training/env YAML structure used by this repository.

Vector Settings

History Frames
Configure vector history independently from scalar history. Negative values refer to past frames, and 0 is the current frame.
- Frame indices are used to retrieve historical observations.
- Example: -16 means 16 frames ago, converted to time by the environment frequency.
- Vector elements with History enabled use these frames in the preview.
Scalar Observations
Configure scalar items and their independent history window. Supported types follow b2d_rlinfra.environment.spaces.
